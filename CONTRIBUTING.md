# Contributing to Corridor

Thanks for helping improve Corridor.

## Principles
- Keep changes factual and reproducible.
- Keep docs aligned with the repo family and the contract source of truth.
- Prefer small, reviewable changes.
- Never commit secrets, tokens, or build artifacts.

## Before you submit
- Read the repo index in `docs/repositories.md`
- Check the release process in `docs/release-process.md`
- Make sure public links resolve
- Keep new content consistent with the Corridor product canon

## Good contributions
- Fix broken links
- Improve repo descriptions
- Add examples or quickstarts
- Clarify public workflows
- Add release notes or rollout notes

## Things to avoid
- Hidden internal implementation details
- Unverified product claims
- Private backend behavior leaking into public docs
