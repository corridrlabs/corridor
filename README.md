# Corridor

Corridor is the public hub for the Corridor open-source ecosystem.

This repository should stay structured, factual, and easy to navigate. It is the place people star first, then follow the links into the deeper public repos.

## Repository files

- `README.md` - public landing page
- `CONTRIBUTING.md` - contribution rules
- `CODE_OF_CONDUCT.md` - community standards
- `SECURITY.md` - security contact and disclosure path
- `LICENSE` - open-source license
- `docs/` - ecosystem docs and repo index
- `public/` - public assets and hub metadata

## Overview

Corridor is an open-source ecosystem for docs, API contracts, MCP tooling, SDKs, plugins, and public release tracking.

The hub repo should do three things well:

1. Tell people what Corridor is.
2. Show them where the public repos live.
3. Give them a safe path to contribute.

## Learn About Corridor

- Read docs and integration guides in `docs`
- Explore docs website source in `docs-site`
- Use API contracts from `openapi` and `api-specs`
- Build AI-native financial automations via `mcp` and `mcp-tools`
- Start quickly with examples and starters

## Open Source Repositories

- SDKs: `sdk-js`, `sdk-python`, `sdk-go`, `sdk-rust`, `sdk-kotlin`, `sdk-swift`, `sdk-php`, `sdk-ruby`, `sdk-dotnet`, `sdk-dart`, `sdk-react-native`
- Plugins and tools: `chatgpt-plugin`, `claude-plugin`, `cursor-plugin`, `terraform-provider`, `postman`
- Platform updates: `changelog`, `status`, `roadmap`
- Supporting repos: `examples`, `webhooks-examples`, `devtools`, `design-system`, `sdk-generator`, `sdk-cli`

## Getting Started

1. Start with the repo index in `docs/repositories.md`.
2. Read the open-source overview in `docs/overview.md`.
3. Use the public docs hub at `corridrlabs/docs`.
4. Inspect the API contract repo at `corridrlabs/openapi`.
5. Follow the MCP guide for agent integrations.

## Public hub structure

This repo should remain small and readable:

- `README.md` for the public landing page
- `docs/` for the repo index and rollout docs
- `CONTRIBUTING.md` for collaboration rules
- `SECURITY.md` for security reporting
- `CODE_OF_CONDUCT.md` for community behavior
