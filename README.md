# Corridor

Corridor is the public hub for the Corridor open-source ecosystem.

This repository should stay small, factual, and easy to navigate. It is the place people star first, then follow the links into the deeper public repos.

## What Corridor is
- The public entry point for the Corridor repo family
- The place to discover docs, API contracts, MCP tooling, SDKs, plugins, and platform updates
- A stable landing zone for open-source users, contributors, and partner engineers

## What belongs here
- Repository index and ecosystem map
- Public contribution rules
- Release and rollout notes
- Links to the canonical docs, API contracts, MCP server, and docs site
