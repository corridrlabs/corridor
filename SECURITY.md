# Security Policy

## Reporting a vulnerability

If you believe you found a security issue in Corridor, do not open a public issue.

Please report it privately to the maintainers using the security contact listed for the org.

## What to include

- A short description of the issue
- The affected repo or file path
- Reproduction steps
- Expected and actual behavior
- Any proof-of-concept details

## What not to include

- Secrets
- Live tokens
- Customer data
- Any material that should not be public
