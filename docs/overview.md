# Open-source overview

Corridor is organized as a public ecosystem of small, focused repositories.

## Public layers
1. Corridor hub
2. Docs and guides
3. Docs site
4. API contracts
5. MCP and agent tools
6. SDKs and libraries
7. Plugins and tools
8. Platform updates
9. Starters and examples

## Canonical rule
Each repository should have one clear job.

## Public repo policy
- Public repos hold source, docs, examples, and build instructions.
- Private repos hold sensitive backend logic, credentials, and live operational configuration.
- Mirror workflows publish only approved source paths.
