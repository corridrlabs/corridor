# Corridor Hub

`corridor` is the public hub for the Corridor ecosystem.

## Purpose

- Give the community one place to discover the public repo family.
- Point readers to the canonical docs, API contracts, MCP tooling, SDKs, and updates.
- Act as the repo people can star to follow the public open-source rollout.

## What belongs here

- High-level repository pointers
- Public release and rollout notes
- Links to docs, API contracts, and developer tooling
- A short overview of the public ecosystem

## Repo structure

The hub repo should stay simple:

- `README.md` - public landing page
- `CONTRIBUTING.md` - contribution rules
- `CODE_OF_CONDUCT.md` - community standards
- `SECURITY.md` - security disclosure path
- `LICENSE` - open-source license
- `docs/index.md` - public hub entry point
- `docs/overview.md` - ecosystem summary
- `docs/repositories.md` - repo index
- `docs/release-process.md` - release flow
- `docs/roadmap.md` - public rollout themes
- `public/README.md` - public assets and metadata

## Start here

- Docs: `corridrlabs/docs`
- Docs site: `corridrlabs/docs-site`
- API contracts: `corridrlabs/openapi`
- MCP: `corridrlabs/mcp`
- SDKs: `corridrlabs/sdk-js`, `corridrlabs/sdk-python`, and the language SDK family
