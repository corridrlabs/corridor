# Platform Updates

Platform update repos keep public users informed without forcing them to inspect backend code.

## Target repos

- `changelog`
- `status`
- `roadmap`

## Purpose

- Publish releases and feature summaries.
- Surface incidents and availability.
- Show planned work without promising delivery dates that are not real.

## Core features

- Human-readable release notes.
- Status history and uptime reporting.
- Roadmap themes and current priorities.
- Links back to canonical docs for technical detail.

## Implementation scope

- Changelog should describe shipped behavior, not just code changes.
- Status should reflect operational reality.
- Roadmap should separate confirmed work from exploration.

## What to avoid

- Fake public commitments.
- Overly technical internals in public release notes.
- Mixing aspirational marketing copy with factual status.
