# EWA Implementation Guide
**Type**: Guide
**Duration**: 8 min read
**For**: HR & Finance Teams

## Overview
Learn how to implement Early Wage Access (EWA) for your employees responsibly and compliantly.

## Key Takeaways
- Setting safe withdrawal limits
- Configuring payroll integration
- Understanding compliance requirements

## Implementation Steps

### 1. Define Policy
Decide on the maximum percentage of earned wages employees can access (recommended: 50%).

### 2. Configure Settings
In the **EWA App**:
- Set withdrawal limits
- Define blackout periods (e.g., 2 days before corridor)
- Configure transaction fees (employer vs. employee paid)

### 3. Employee Onboarding
Invite employees to the Corridor mobile app where they can view their earned wages and request advances.
